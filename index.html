使用说明
  1. PS5 浏览器打开本页：仅检查是否为可破解固件（7.00–13.60）；符合则显示「一键破解」，否则提示不支持。不会自动开始、也不会探测端口。
  2. 破解成功后出现 payload 面板；点「一键加载全部」（kstuff → ftpsrv → panplay），或各卡片单独发送。加载结束后会探测本机 127.0.0.1 端口。
  3. 传文件、放自制软件可用 /data/homebrew 等目录，通过 ftp.html（2121）管理。
  4. 也可以用 PC 手动发送（主机 IP 替换）：Linux/macOS nc 192.168.x.x 9021 < kstuff.elf；Windows 可用社区 send_payload.ps1 脚本。
  5. 重启后一切还原，需要重新走一遍本页流程；稳定性提示与免责声明见仓库 README。
组件关系
  • Relapse 漏洞链（WebKit 用户态 → aio_multi_wait 内核 UAF → 提权）：跑通后由 kexp 在内核上下文拉起 elfldr 并监听 9021。
  • elfldr：接收 ELF 字节流并加载执行，是后续所有 payload 的入口（本页通过 ROP 直接向 127.0.0.1:9021 发送）。
  • ftpsrv：独立 FTP 服务器（2121），不依赖任何 HEN 组件，elfldr 在就能发；配 /ftp.html 网页管理文件。
  • panplay：百度网盘安装器（8734），网页端装游戏；访问码见主机通知。
  • kstuff-lite：内核补丁集（FSELF/FPKG、挂载等），后续 payload 的基础。
